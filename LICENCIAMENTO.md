# Situação de licenciamento — verificação pendente

Este documento registra o que foi e o que não foi confirmado. Não é uma licença de uso ou redistribuição.

## Mariana e Default Dark

Esta extensão contém uma transposição de configurações dos arquivos Mariana e Default Dark fornecidos pelo usuário. Ainda não foi identificada uma licença ou autorização dos titulares que permita afirmar que esses arquivos específicos podem ser adaptados e redistribuídos publicamente nesta extensão.

O repositório oficial `sublimehq/Packages` contém uma licença permissiva para arquivos daquele repositório. Não foi estabelecido que os arquivos Mariana e Default Dark utilizados nesta adaptação estão abrangidos por ela. Portanto, seu texto não foi copiado nem apresentado como licença desta extensão.

Referência consultada: https://github.com/sublimehq/Packages/blob/master/LICENSE

A EULA do aplicativo Sublime Text também não foi tratada como uma autorização específica para distribuir esta adaptação: https://www.sublimetext.com/eula

## Campo UNLICENSED

O `package.json` mantém `"license": "UNLICENSED"` como indicação de que o pacote não oferece uma licença de uso geral. Esse valor não significa domínio público, não resolve direitos de terceiros e não autoriza publicar a adaptação.

As alterações próprias, a documentação e as imagens não foram colocadas sob uma nova licença nesta atualização. A escolha de uma licença para contribuições próprias deve distinguir essas contribuições dos componentes originais e respeitar os direitos aplicáveis.

## Antes de disponibilizar publicamente

1. Localizar os avisos de copyright e a licença dos arquivos de origem exatos, ou obter autorização escrita dos respectivos titulares para adaptação e redistribuição.
2. Conferir se a permissão abrange tanto o esquema Mariana quanto a base de interface Default Dark.
3. Preservar os avisos exigidos e incluir o texto da licença aplicável, sem substituir direitos de terceiros por uma licença escolhida apenas para a adaptação.
4. Atualizar este documento e o campo `license` com informações verificadas. Se houver várias licenças, identificar quais arquivos cada uma cobre.

O uso de um repositório público e a inclusão de créditos não substituem essas permissões. Orientação geral do GitHub: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository

Esta preparação documental não confirma autorização para publicação pública. Nenhum repositório foi publicado como parte desta atualização.
